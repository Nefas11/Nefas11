# Nefas11

Agentic software development, with the guardrails built in.

I build systems where AI agents do real work and are held to it: task
contracts, independent verification of what an agent claims, misalignment
detection while it runs, and a reputation that follows the agent. Most of it
is Python with zero dependencies, so it drops into an existing setup.

## Repositories and skills

Six skills for [OpenClaw](https://github.com/openclaw) with 6k+ downloads on
[ClawHub](https://clawhub.ai/nefas11). The code behind them lives here.

- [governed-agents](https://github.com/Nefas11/governed-agents): deterministic verification and reputation scoring for AI sub-agents. A hallucinated "done" costs the agent its score. [On ClawHub](https://clawhub.ai/nefas11/governed-agents)
- [agent-monitor](https://github.com/Nefas11/agent-monitor): two-phase misalignment detection for coding agents, sync blocking plus async LLM review
- [supervised-agentic-loop](https://github.com/Nefas11/supervised-agentic-loop): Brainstorm → Plan → Implement → Review → Verify → Evolve, with every tool call monitored. Runs on OpenClaw, Antigravity and Claude Code. [On ClawHub](https://clawhub.ai/nefas11/supervised-agentic-loop)
- [swipenode](https://github.com/Nefas11/swipenode): web extraction for agents without a headless browser, pulls the JSON out of Next.js and Nuxt pages at a fraction of the tokens. [On ClawHub](https://clawhub.ai/nefas11/swipenode-2)
- [openclaw-superpowers-workflow](https://github.com/Nefas11/openclaw-superpowers-workflow): subagent orchestration with quality gates
- [public-skills](https://github.com/Nefas11/public-skills): skills for Claude Code and Codex, starting with `first-principles-reduction`: question, delete, simplify, accelerate, automate, in that order

Also on ClawHub: [Brainstorming](https://clawhub.ai/nefas11/brainstorming-2) and
[Writing Plans](https://clawhub.ai/nefas11/writing-plans-2), adapted from
[obra/superpowers](https://github.com/obra/superpowers), and
